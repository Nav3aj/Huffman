How does Huffman Coding work?
  1. Count characters. The program counts how often each byte appears in the text.
  2. Build a tree. It joins the two least-frequent items again and again to create a Huffman Tree.
  3. Give each item a code. Moving left means 0; moving right means 1. More common items usually get shorter codes.
  4. Compress and restore. The codes are saved in a .huff file. The same tree is used to get the original bytes back.

Algorithm and complexity (for the assignment)

Huffman Coding is a Greedy Algorithm. At each step, it combines the two items with the lowest frequencies.

Counting frequenciesO(n)
Building the treeO(k log k)
Generating codesO(k)
Encoding / decodingO(n + B) / O(B)

n = number of input bytes; k = number of different byte values (at most 256); B = number of encoded bits. The tree uses O(k) space.
